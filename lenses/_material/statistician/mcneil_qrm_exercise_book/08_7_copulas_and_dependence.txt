Exercise 7.31 (Axioms of concordance)
Spearman’s rho and Kendall’s tau are measures of concordance. According to Scarsini (1984),
such measures should fulﬁll a set of desirable axioms. Let (X, Y ) be a pair of random variables
with continuous marginal distribution functions and joint distribution function F. Let the
measure of concordance be κ(F) = κ(X, Y ). The axioms are:
i)
(Domain) κ(X, Y ) is deﬁned for every such pairs (X, Y );
ii) (Range) −1 ≤κ ≤1 with κ(X, Y ) = −1 for countermonotonic random variables and
κ(X, Y ) = 1 for comonotonic random variables;
iii) (Symmetry) κ(X, Y ) = κ(Y, X);
iv) (Independence) If X and Y are independent, then κ(X, Y ) = 0;
v) (Change of sign) κ(−X, Y ) = −κ(X, Y );
vi) (Coherence) If (X1, Y1) and (X2, Y2) are pairs of random variables with copulas C1 ≤C2
ordered pointwise, then κ(X1, Y1) ≤κ(X2, Y2);
vii) (Continuity) If (Fn)n∈N is a sequence of continuous bivariate distribution functions which
converges pointwise to the continuous distribution function F, then limn→∞κ(Fn) = κ(F).
a) Verify these axioms for Spearman’s rho.
b) Provide an example which shows that κ(X, Y ) = 0 does not imply independence of X, Y .
Hint. Consider the uniform distribution on the unit circle.
