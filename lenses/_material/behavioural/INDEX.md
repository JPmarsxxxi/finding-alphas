# Behavioural lens — corpus index

**Entry point.** Grep this file to find the right source, open that source's own `INDEX.md` where it
has one, then open ONLY the chapter or section you need. Every PDF has a `.txt` twin — grep the text,
never open a PDF to browse.

Selection rule: **academically solid × institutionally applied.** Both halves are present.
